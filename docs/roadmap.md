# AhorraAI v4 — Roadmap

## Fases de Evolución del Producto

- **MVP 0.1**: Demo interactiva + Negocios + Oportunidades + Cooperación + Vigo Pilot Dataset (Estado actual).
- **MVP 0.2**: Conexión con bases de datos persistentes (PostgreSQL / Supabase / Google Sheets) y pipeline de sincronización.
- **MVP 0.3**: Agentes autónomos y canales WhatsApp / Telegram / Hardware 3D IoT.
- **MVP 0.4**: Smart Business (Nodos inteligentes de comercio con agentes propios).
- **MVP 0.5**: Smart Street (Ejes comerciales automatizados y paneles de calle).
- **MVP 0.6**: Observatorio AhorraAI con panel para administraciones públicas y asociaciones de comerciantes.
- **V1.0**: Protocolo de Comercio Local Cooperativo descentralizado.
- **V2.0**: Gemelo Digital Urbano Comercial (Digital Twin multi-ciudad).
